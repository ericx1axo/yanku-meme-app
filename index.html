🌐 How to Open via Yanku.com

By default, local servers run on http://127.0.0.1:8888. To open this site directly by typing http://yanku.com:8888 in your computer's web browser:

Option A: Local Windows Hosts File Mapping
1. Open Notepad as Administrator.
2. Open C:\Windows\System32\drivers\etc\hosts
3. Add this line at the end: 
127.0.0.1   yanku.com
4. Now typing http://yanku.com:8888 will open your local app!
Option B: Live Domain Deployment (Vercel / Netlify)
1. Upload this folder to GitHub.
2. Connect your repository to Vercel or Netlify.
3. Point your DNS records for yanku.com to Vercel/Netlify for global access!
