# 🚀 Yanku.com - Automated Random Meme Generator & Ad Platform

A web application for **Yanku.com** featuring an automated random meme generator script, live Auto-Pilot stream, interactive HTML5 Canvas meme studio, and responsive ad placement units.

---

## 🌟 Key Features

* **Automated Meme Generator**: Dynamic Auto-Pilot script that generates viral programmer and internet humor memes automatically every 3.5 seconds.
* **Interactive Canvas Meme Studio**: Customize top/bottom text, change themes (Cyberpunk, Lava Red, Emerald Green), and export high-res PNG memes.
* **Monetization & Ad Units**: Responsive ad placements (728x90 Top Leaderboard, 300x600 Sidebar Skyscraper, Sticky Footer) ready for Google AdSense / Media.net integration.
* **VS Code Launch Ready**: Pre-configured `.vscode/launch.json` for one-click server debugging.

---

## 🌐 Opening `yanku.com` Locally

When running locally, web servers default to `http://127.0.0.1:8888`.

### To open `http://yanku.com:8888` in your computer's browser:
1. Open **Notepad** as Administrator.
2. Open the file `C:\Windows\System32\drivers\etc\hosts`.
3. Add the following line at the end:
   ```text
   127.0.0.1   yanku.com
   ```
4. Save the file.
5. Now browsing to **`http://yanku.com:8888`** will open your local app directly!
